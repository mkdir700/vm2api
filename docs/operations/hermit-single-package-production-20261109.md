## 生效行为

Hermit 只提供一个当前安装包。
页面不再显示版本列表和版本 select。
上传新包只替换当前安装包。现有 VM 在重装后才更新。
系统保留已有 VM、暂存记录和未完成回滚实际需要的部署文件。
系统在上传或重装完成时清理无引用文件。

vm2api 在停止原槽位前检查客体镜像。
检查覆盖 Ubuntu、架构、glibc 和固定 tmux 摘要。
没有合格镜像时，系统使用随控制平面发布的 Dockerfile 构建独立本地镜像。
镜像准备失败时，系统保留原槽位。
创建目标槽位时，系统使用已校验的不可变镜像 ID。

原有槽位选择、凭据、活动指针、配置和其他容器身份保持不变。
全局“官方 Claude Code 家族透传”仍未启用。
全局“工具参数流式下发”仍开启。

## 管理员操作

警告：安装成功后，VM 保持停用。系统会清理旧容器。

1. 刷新后台，打开“内核”页面。
2. 在“VM 安装”区域选择目标 VM。
3. 在“安装内核”select 中选择 Hermit。
4. 检查当前包为 `0.0.0-production.14c939f`。
5. 单击“安装”，再确认“重装并停用”。
6. 等待成功，然后启动 VM 并启用调度。
7. 验证真实账号请求和外部工具续接。
