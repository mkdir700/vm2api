# Hermit 单安装包契约

## 目标

Hermit 只保留一个可安装包。上传替换当前包，不更新现有 VM。
VM 通过统一安装接口使用当前包。页面不提供历史列表或版本选择。
版本号和摘要只用于来源核对。

正在使用的旧内核文件属于 VM 的部署文件，不属于可安装包目录。
系统必须保留这些文件，直到 VM 重装完成或回滚结束。
系统随后清理无引用文件。系统不提供历史包选择接口。

## 实现前失败清单

1. 上传新包后，目录仍返回多个可安装包。
2. 页面仍要求选择 Hermit 版本。
3. 不传版本的统一安装请求被拒绝。
4. 请求可以选择已经替换的历史包。
5. 上传损坏包后，当前包指针变化。
6. 重复上传损坏当前包或重复下载官方 CLI。
7. 清理删除活动 VM、暂存 VM 或未结束回滚所需的文件。
8. 重装完成后，无引用内核文件仍长期保留。
9. 上传与安装并发时，确认内容与实际安装内容不一致。
10. 页面确认后发生包替换，服务器静默安装另一包。
11. 原包目录没有当前指针时，系统按版本字符串猜测当前包。
12. 当前指针损坏、指向链接或身份不匹配时，系统绕过校验。
13. 新包更新停止 VM 或改写生产配置。
14. 兼容 inspector 允许未引用的历史包再次安装。

- `test/e2e/hermit-kernel-page.e2e.test.mjs`：真实构建产物和浏览器，单包展示、无版本 select、统一安装确认。
