## 页面与管理员操作

独立 Hermit card 已删除。
“可用内核”区域将 cli-node、CRAG 和 Hermit 列为三个并列内核。
Hermit 上传对话框只管理版本，不操作槽位。
VM 使用同一个安装内核 select 选择 cli-node、CRAG 或 Hermit。
选择 Hermit 后，另一个 select 选择具体版本。
单台和批量安装均使用 `/api/panel/kernels/install`。

警告：统一安装流程会重建涉及 Hermit 的槽位容器。
警告：安装成功后，系统清理旧容器，并将 VM 保持停用。
警告：旧容器清理后，不能依赖上一轮临时切换记录回滚。
需要恢复原内核时，在同一个 select 中选择原内核，再执行安装。

1. 刷新后台，打开“内核”页面。
2. 在“VM 安装”区域找到目标 VM。
3. 在“安装内核”select 中选择 Hermit。
4. 选择版本 `0.0.0-production.9cdb646`。
5. 单击该 VM 的“安装”按钮。
6. 检查确认对话框中的 VM、内核和版本。
7. 确认“重装并停用”。
8. 等待安装成功。
9. 按正常 VM 流程启动并启用调度。
10. 执行真实账号请求与外部工具续接验证。

不必修改全局协议开关。
“官方 Claude Code 家族透传”保持未启用。
“工具参数流式下发”保持开启。
