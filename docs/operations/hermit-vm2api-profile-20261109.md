## 实现

系统提示词支持字符串和文本块数组。
Hermit 以两个换行连接文本块，并写入权限为 `0600` 的私有文件。
内部 Claude Code 使用原生 `--system-prompt-file` 读取该文件。
首次请求、工具续接、凭据更新和完整历史恢复使用相同的系统提示词契约。
缓存标记不进入提示词正文。实际序列化和缓存仍由原版 CLI 控制。

工具流式标记只接受布尔值。
Hermit 将统一策略映射到原版 CLI 的细粒度流式开关。
启用流式时，Hermit 允许原生 beta 序列化路径。
关闭流式时，原有禁用策略保持不变。
既有出站检查会验证实际请求中的标记，防止开关被静默忽略。

工具目录检查仍比较全部工具名称、描述和参数结构。
检查只忽略已验证的传输标记及固定版本 CLI 的合法 MCP 归属元数据。
Hermit 不改写实际请求中的这些字段，也不增加私有原版 hook。
详细决策见 Hermit 仓库的 `adr/0047-managed-system-and-tool-streaming.md`。

新包声明 `system_prompt` 和 `eager_tool_streaming` 能力。
vm2api 根据包能力检查现有设置。
旧包没有这些能力时，系统仍会拒绝不支持的组合。
应用内核不会改写全局配置。

## 管理员操作

警告：先完成所选槽位的外部工具调用。

1. 刷新后台页面。
2. 打开所选槽位的“推理内核”，或打开“内核”页面。
3. 选择 `0.0.0-production.9cdb646`。
4. 单击“切换并应用”。不要选择旧的 `7204d42` 包测试本轮新组合。
5. 完成真实账号请求和工具调用验证。
6. 验证通过后，再单击“确认保留当前内核”。
7. 需要恢复原内核时，单击“回滚上次切换”。

不必打开全局透传，也不必关闭工具参数流式。
详细切换规则见[现有槽位的 Hermit 切换与回滚](hermit-kernel-switch.md)。

## 明确边界

同一请求中的工具流式策略应统一。
缺失标记按 false 处理。混合逐工具的 true 和 false 会在启动前被拒绝。
标准 vm2api 全局开关产生统一策略。
系统提示词输入上限为 1 MiB。空系统输入保留原生默认值。
活动原生会话仍固定其提示词、模型和工具目录，不热改已有进程。
本轮模拟验收不证明真实账号可用性或服务端无法识别桥接。
